# Living Earth 3D branding

`icon.png` is original AI-generated branding artwork created for this project with OpenAI image generation. `icon.ico` contains 16, 24, 32, 48, 64, 128 and 256 pixel variants for Windows desktop and taskbar use. Branding is artistic and is not a geographic dataset. The Earth surface maps used by the interactive globe are credited separately in `earth/ATTRIBUTION.md`.

0.5.4 replaces the mark with an original OpenAI-generated luminous blue/green Earth on a midnight rounded-square tile. Prompt: a clean premium Earth icon, thin cyan atmosphere, restrained sunrise, strong small-size contrast, no text; transparent outside the tile. Generated with the built-in image tool, then packaged into the 512px PNG and the seven ICO resolutions. Versioned shortcut icon paths avoid reusing the previous executable-icon cache entry.
