# Living Earth 3D 0.5.0 preview

Download LivingEarth3D-Setup-0.5.0.exe, double-click, install, then open the desktop shortcut. This is the single Windows executable installer; no ZIP or separate runtime is needed.

New: spacious responsive interface, ultrawide/4K/5K layout, place search, official-camera directory with globe journeys, on-request USGS earthquake observations, and four screensaver styles.
