# Living Earth 3D 0.4.0 Windows installer preview

Download **LivingEarth3D-Setup-0.4.0.exe**. One self-contained installer, no ZIP extraction, terminal or separate runtime.

New: genuine 4K detail mode, independent offline clouds, optional stars/Moon, power saving, saved visual settings and preview update discovery. Existing intro, native Earth icon, controls, destinations and favorites are preserved.

The Moon/stars are artistic backdrops; cloud animation is offline artwork, not live weather. Unsigned previews require manual installation; automatic replacement requires matching trusted signatures and package checksums.

Validation: 56 behavior checks, three intro render stages, eight quality/resolution cases, native icons, exported startup/rendering and installer payload/integrity checks. The user confirmed the previous 0.3.0 installed and ran on Windows; 0.4.0 upgrade/hardware validation remains outstanding.
