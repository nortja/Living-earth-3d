# Living Earth 3D 0.6.0 — Development Preview

Download LivingEarth3D-Setup-0.6.0.exe, double-click, install, then open the Living Earth 3D Development desktop shortcut. One EXE; no ZIP, terminal, separate runtime or account. Development uses a separate install folder, registry/settings and update feed. Existing 0.5 preview delivery is unchanged.
