# Unreleased camera elapsed-age and retained-image reliability

November 7–8, 2026. Unchanged-image warnings measure elapsed age using monotonic engine milliseconds, rather than subtracting wall-clock UTC values. A computer clock correction cannot change the elapsed-age calculation. UTC retrieval/check values and provider Last-Modified remain separately labeled; capture time is still unverified. The same warning is now retained when a refresh fails and the last good image remains visible, so a network error does not conceal an already-delayed provider frame. No request, refresh cadence, memory limit, preference or updater behavior changes.

Targeted regression tests cover identical HTTP 200 bytes, HTTP 304, failed refresh retention and warning persistence, changed-image reset, future UTC display metadata, and existing provider-specific five-/thirty-minute thresholds. The follow-up [Linux and Windows run 42497968977](https://github.com/nortja/Living-earth-3d/actions/runs/42497968977) passed all 357 camera assertions on each platform: viewer 41, revalidation 231, expansion 26 and wall 59. The native viewer rendered the retained image and failure warning with zero failures on both platforms. The earlier [release-verifier run 42390478383](https://github.com/nortja/Living-earth-3d/actions/runs/42390478383) also passed its 12 verifier tests.
