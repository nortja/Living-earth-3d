LIVING EARTH 3D - WINDOWS TESTING PROTOTYPE

Extract the complete ZIP, open this folder, and double-click LivingEarth3D.exe.
No Godot installation, internet connection, or separate game-data file is required.
The Godot runtime and all game assets are embedded in the executable.

Target: Windows 10/11 x64, OpenGL 3.3-capable graphics driver.
This is an unsigned prototype, not an installer or Windows screensaver.

CONTROLS
Drag with the left mouse button: orbit the globe
Mouse wheel: zoom in or out
Space or Auto rotation switch: pause/resume rotation
Destination menu: travel to a place and read its fact
Surprise me: visit a different place
Home or Reset view: return to the default rotating globe
Esc: quit

Please test rotation, orbit/dragging, zoom, destinations, reset, and window resizing.
Report Windows version, GPU/driver, display resolution/scaling, and any error text.
Native Windows behavior still needs testing; cloud tests ran on Linux.

The application uses only bundled offline content. Live cameras, screensaver
integration, multi-monitor coordination, and automatic updates are future work.
