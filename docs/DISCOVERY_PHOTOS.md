# Discovery photograph credits

Photographs are bundled for offline exploration. They are not live camera images and are not reconstructions of historical scenes. Resized derivatives retain their individual licenses; they do not change the license of the application code. Metadata was checked 2026-10-20 against each Wikimedia Commons file record.

Every arrival thumbnail shows creator/license credit. The full viewer provides source and license links and identifies resizing/re-encoding. Assets are bounded to 1280 pixels on the longest edge. EXIF was omitted; creator, source, license, modification disclosure, source revision/file timestamp and SHA identifiers are retained in data/discovery_photos.json. No network request is made to display a photograph.
