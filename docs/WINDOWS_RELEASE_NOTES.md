An offline Windows x86-64 Explorer prototype with bundled Godot runtime and assets. Extract the ZIP and double-click `LivingEarth3D.exe`; no Godot installation is required.

Features: rotating globe with Natural Earth coastlines, drag-to-orbit and wheel zoom, pause/reset controls, six curated destinations, smooth camera journeys, geographic markers, and Surprise me.

Validation: 67 automated interaction checks passed; Linux software OpenGL rendering and embedded game-content startup passed. Native Windows testing is still required. This build is unsigned and is not a Windows screensaver or installer.

Target: Windows 10/11 x64 with an OpenGL 3.3-capable graphics driver. The ZIP includes first-run instructions and public-domain map attribution. Compare the ZIP hash against the attached SHA256SUMS.txt before testing.

Please report Windows version, GPU/driver, resolution/scaling, and any launch, rendering, or input issues. Live cameras, screensaver integration, multi-monitor coordination, and automatic updates are not yet implemented.
