# Local saved-place backups

Explore → Saved → Export saved places backup opens a file chooser. Select a JSON filename/location. Import and merge saved places chooses an existing backup, adds new coordinates and retains your current places. The status reports added, duplicate and over-capacity entries. Backups contain saved names, coordinates, notes and HTTPS source links; nothing is uploaded or fetched. Keep/copy the chosen file wherever you want. Native screensavers do not import or export. The chooser is released on in-app saver preview.

Existing entries win using the same four-decimal coordinate key as ordinary saved places. Import never replaces an existing name/note or removes entries. The collection remains bounded to 50. A malformed or wrong-format file rejects the entire import before preferences change. There is no automatic import at startup. Exporting an empty collection is valid. This backs up saved places, not camera collections, curated legacy favorites, application settings, current provider data or the signing key.

The format identifies `LivingEarth3D-saved-places`, schema 1. Input is bounded to 1 MiB and 50 entries; names, notes, types and finite in-range coordinates are checked. Names with control/invalid replacement characters are rejected; non-HTTPS/control-containing source links are removed. Unknown extra fields are ignored, never executed. A chosen export writes and flushes a temporary sibling and renames only after successful output; failed writes/rename report an error and remove their temporary file. This is not an encryption or power-loss guarantee.

Validation exercises Unicode roundtrip, exact chosen-file I/O and overwrite, unsupported/malformed envelopes, all-or-nothing invalid rows, bounds, source filtering, duplicate/capacity preservation, reset/cancellation and no requests. Native layouts and actual installed Windows callbacks exercise the exported code and local file merge. The OS chooser uses Godot's supported native file dialog where available; physical chooser interaction is a field observation, not inferred from callback fixtures. See VALIDATION-0.18.0.md.
